# Readme

This code will essentially extract our results from the usability_results.csv folder and display bar charts for the likert chart answers from the survey. The usability results is directly extracted from the google survey. 

## Build instructions

To run the code, simply follow the instructions in the notebook, these instructions will enable you to visualise the graph accordingly.

### Requirements

* Python 3.10.8
* Packages: 
    * pandas
    * matplotlib
* Tested on Windows 10

### Build steps

Pip install the required packages as shown above and then you can run the cells in the notebook.
